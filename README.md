# iris_classification_IEEE

# Project Overview
This project predicts the species of iris flowers using four
measurements: sepal length, sepal width, petal length, and
petal width.

Two classification algorithms, Decision Tree and K-Nearest
Neighbors (KNN), are trained and compared.

# Dataset
The Iris dataset contains 150 samples and three flower species.

Dataset source:
https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html

# Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab (Jupyter Notebook)

# Setup Instructions
1. Open Google Colab.
2. Upload or open iris_classification.ipynb.
3. Run all cells from top to bottom.

The dataset is loaded directly using scikit-learn.

# Results
- Decision Tree Accuracy: 93.33%
- KNN Accuracy: 93.33%

# Conclusion
The Decision Tree and K-Nearest Neighbors models both achieved an accuracy of 93.33% on the test dataset. Each model correctly classified 28 out of 30 flowers. Neither model performed better in terms of accuracy on this test set. This project helped me understand how different machine learning algorithms can achieve similar results despite using different classification methods.
